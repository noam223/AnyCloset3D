action

CKAN's Action API is a powerful, RPC-style API that exposes all of CKAN's core features.

All endpoints support POST requests with an application/json or a multipart/form-data body. Use an application/json POST request when nested json parameters are required.

Use a multipart/form-data POST request when file uploads are required. Read-only endpoints (*_show, *_list, *_search etc.) accept GET requests with query parameters. Responses are returned in a JSON envelope. On success:json{ "help": "url to complete endpoint help", "success": true, "result": {...}} or on errors:json{ "help": "url to complete endpoint help", "success": false, "error": { "__type": "error type", "message": "error message", "field-with-error": ["first-error", "second-error"], ... }}
