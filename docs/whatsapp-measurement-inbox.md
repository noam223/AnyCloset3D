# קישור העלאה למודד

המודד נכנס לכתובת ייחודית, בוחר לקוח מהפרויקטים (או כותב שם ידני), ומעלה PDF / תמונות.

## איך זה עובד

1. בפרופיל: **קישור העלאה למודד** → צור / הצג קישור → העתק
2. שולחים את הקישור למודד (וואטסאפ, SMS, מייל)
3. אם בחר לקוח מהרשימה — הקבצים מתחברים ישר לפרויקט
4. אם כתב שם ידנית — הקבצים מגיעים לתיבת **מדידות חדשות** לקישור ידני

## קבצים מותרים

PDF, JPG, PNG · עד 12 קבצים · עד 18MB לקובץ

## אבטחה

הקישור כולל טוקן סודי. אם דלף — לחצו **החלף קישור** בפרופיל. הקישור הישן מפסיק לעבוד.
